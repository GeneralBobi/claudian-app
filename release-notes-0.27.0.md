# Claudian 0.27.0 — Your voice, from the desktop too

- Enroll your voice on this computer ("Sesimi tanıt", about 25 seconds of reading). The reading is never saved; only a voiceprint stays on this computer, shared with the phone.
- Phone card shows live connection through the Yüzük cloud: connected phones, recent recordings, cloud heartbeat.
- Microphone picker skips virtual devices (SteelSeries Sonar, Voicemeeter) by default.
- Vault protocol: new "Notes from a recording" section, so every connected AI writes voice notes the same way.
