# Claudian 0.29.0

- Settings → **Remove all connections**: takes Claudian out of every connected AI in one step — its instructions, skills and connection files, the cloud permissions you granted, and this device's remote connection. Your notes folder is not touched, and a connection file you edited yourself is left in place and listed. Instructions you added to an AI account's own memory are removed inside that app.
- Recordings made on the phone now reach this computer's memory too. The Yüzük engine hands each finished note to Claudian, which writes it into your notes folder the same way as a desktop recording, with its reminders and receipts.
- Undated obligations are tracked. When a recording contains work with no date yet (an assignment given in class, a plan to make), it goes to your open-loop panel instead of staying buried in the note.
- Reminders keep their hour: "quiz at 10:30" is written as "Quiz · saat 10:30", so the phone and the calendar can use it.
