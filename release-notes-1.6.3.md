# Claudian 1.6.3

Phone app Yüzük 0.11.3 ships with this release.

- **Your phone gets the note too.** When your computer writes the note of a phone recording, the phone now writes the same file into its own Obsidian vault. Sync sees one note, not two.
- **Cleaner notes.** The line with the recording length and sentence count under the title is gone, and so are the automatic "İlgili" links. A note links only to the course or event it belongs to.
- **Smaller, cleaner engine package.** The old manual-install scripts and the developer README no longer ship in the engine package; setup runs from Claudian itself. Machine-specific start steps moved out of the package.
- The phone install page shows where the pairing code comes from when the link has none.
