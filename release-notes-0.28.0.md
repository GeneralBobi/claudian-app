# Claudian 0.28.0

- Background services: Claudian can keep your own local services (a tunnel, a local server) running from the tray, with no console windows. It restarts them if they stop and stops the ones it started when you quit. Configure them in `services.json` in the Claudian data folder; with no such file nothing runs.
- The tray menu shows each background service and its state.
- The device connection now suggests the neutral relay address `https://relay.claudian.app`.
